# 24th system

Reusable React components and examples, extracted from the public 24th component registry.

## Project facts

- Documentation: https://dsaltaren.com/design-system
- This repository is a standalone source snapshot, with no portfolio history or private application files.

## Stack

- React 19, TypeScript and Vite. Dependencies are pinned in package-lock.json.

## Hard decisions

- Keep reusable code in src and examples in examples.
- Use fictional sample data. Do not add personal media, proprietary fonts, credentials or deployment configuration.
- Preserve the Rune Icons license in src/rune-icons-LICENSE.txt.

## Working agreements

- Run npm run build before sharing changes.
- Keep this file under 200 lines.
